## Project overview

This project presents an end-to-end Business Intelligence solution
designed to transform multiple operational and external data sources
into interactive dashboards and actionable business insights.

The analysis covers:

- Sales performance
- Product and market analysis
- Outlet segmentation
- Stock availability
- Delivery and logistics performance
- Geographic analysis
- Clustering and forecasting
